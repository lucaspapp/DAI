El problema

Cuando el bastón no alcanza

El bastón blanco es una herramienta fundamental para la movilidad, pero determinados obstáculos elevados pueden quedar fuera de su alcance.

Una situación cotidiana

En interiores pueden aparecer objetos ubicados a una altura que el bastón no detecta fácilmente. Esto puede generar golpes o situaciones incómodas durante el desplazamiento.

01
Puertas de muebles abiertas

Objetos que sobresalen a la altura del rostro.

02
Estantes y repisas

Elementos elevados que pueden quedar fuera del recorrido del bastón.

03
Objetos a la altura de la cabeza

Obstáculos frontales difíciles de anticipar.

Tecnología

¿Cómo funciona DAI?

El dispositivo utiliza detección de distancia y una señal háptica para advertir al usuario.

01 — DETECTA

Detecta el entorno

Un sensor frontal mide la distancia hacia los objetos que se encuentran delante del usuario.

02 — PROCESA

Analiza la distancia

El ESP32 procesa la información obtenida por el sensor para determinar cuándo debe generarse una alerta.

03 — ALERTA

Vibra

Cuando se detecta un obstáculo dentro del rango establecido, el dispositivo genera una alerta mediante vibración.

Características

Diseñado para ser simple

DAI busca concentrarse en una función concreta: detectar obstáculos elevados y comunicarlo de forma discreta.

◉

Detección frontal

Sensor orientado hacia el frente para identificar obstáculos elevados.

≋

Alerta háptica

La información se transmite mediante vibración, evitando depender de una señal sonora.

+

Complementario

Está pensado para complementar el bastón blanco, no para reemplazarlo.

◆

Formato discreto

El concepto busca integrarse de manera sencilla al usuario mediante una banda para la cabeza.

El proyecto

Un dispositivo pensado para interiores

DAI se encuentra actualmente en etapa de prototipo y validación.

Tecnología detrás de DAI

La primera versión del dispositivo está basada en componentes electrónicos accesibles y una arquitectura sencilla, buscando priorizar funcionalidad, comodidad y facilidad de uso.

Importante DAI no busca reemplazar el bastón blanco. Su objetivo es funcionar como una herramienta complementaria para situaciones específicas dentro de espacios interiores.

Primer prototipo

  • ESP32
  • Sensor de distancia HC-SR04
  • Batería recargable
  • Circuito de carga y regulación
  • Motor de vibración
  • Banda para la cabeza
